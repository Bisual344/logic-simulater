7408 AND IC

7408은 2입력 AND 게이트 4개가 들어 있는 14핀 IC입니다. 14번 핀은 5V, 7번 핀은 GND에 연결합니다.

입출력 표시: A, B는 입력(Input), Y는 출력(Output)입니다. 예를 들어 1A와 1B에 0/1 신호를 넣으면 1Y에서 계산 결과가 나옵니다.
  • VCC: 14번 핀, +5V 연결
  • GND: 7번 핀, 접지 연결
  • 주의: 홈 또는 점 표시가 있는 쪽을 기준으로 핀 번호를 확인합니다.

STEP 3

게이트 합성 회로 개념 이해하기

기본 게이트를 조합하면 덧셈 회로, 선택 회로, 표시 회로 같은 더 복잡한 디지털 회로를 만들 수 있습니다.

A ─┐
B ─┼─ XOR ─ Sum
   └─ AND ─ Carry

반가산기

두 1비트 입력 A, B를 더해 합 Sum과 자리올림 Carry를 출력합니다.

Sum = A ⊕ B / Carry = A·B

A,B,Cin → XOR/AND/OR → Sum,Cout

전가산기

A, B뿐 아니라 이전 자리에서 올라온 Cin까지 더하는 회로입니다.

Sum = A ⊕ B ⊕ Cin

STEP 4

소자 연결 원리 그림으로 보기

직접 배치하는 화면 대신, 논리회로 실험에서 전원·IC·입력 스위치·LED가 어떻게 연결되는지 한눈에 보이도록 구성했습니다.

+5V 전원 레일
GND 접지 레일
입력 스위치 A/B
0 또는 1 신호 생성
→
논리 게이트 IC
VCC=14번, GND=7번
A,B 입력 → Y 출력
→
출력 LED + 저항
Y=1이면 켜짐
기본 연결 순서
  1. IC 14번 핀을 +5V에 연결한다.
  2. IC 7번 핀을 GND에 연결한다.
  3. 스위치 출력을 A, B 입력 핀에 연결한다.
  4. Y 출력 핀을 저항과 LED에 연결해 결과를 확인한다.
