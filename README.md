# 논리회로 실습 V5
압축 해제 후 `index.html`을 브라우저에서 여세요.

## V5 주요 변경 사항
- **5단계(프로젝트 제작) 화면 떨림·버그 수정**:
  - 부품 제목, 단자, 재료 버튼에 마우스를 올릴 때 연결 안내창(`#connectionInfo`)의 높이가 변하면서 아래 보드가 밀려 무한 루프로 덜덜 떨리던 현상(레이아웃 스래싱) 완벽 해결
  - 보드 내부 단자 버튼 호버 시 `translateY(-2px)` 이동으로 인해 마우스 경계에서 깜빡이던 현상 제거
  - 모범 배선 및 전체 배치 시 3줄 부품 간격을 넉넉히 넓혀 부품 겹침 해결 및 배선 좌표 계산(`offsetLeft/Top`) 안정화
- **6단계 실전 모의고사 & 순위표 & 오답 기록 개편**:
  - **닉네임 입력 후 시작**: 응시자 닉네임을 먼저 입력하고 모의고사를 시작합니다.
  - **50문제 중 랜덤 10문제 출제**: 문제은행 50문항에서 매번 무작위로 10문제를 뽑아 출제합니다.
  - **100점 만점 채점**: 한 문제당 10점씩 총 100점 만점으로 점수를 계산합니다.
  - **순위표(랭킹) 자동 기록**: 채점 즉시 점수순(동점 시 소요 시간순)으로 순위표가 갱신되며 브라우저에 저장됩니다.
  - **닉네임별 틀린 문제 번호 및 상세 오답노트**: 하단에 `닉네임 - 몇 번 문제 틀림 (50문항 중 #몇 번)` 요약 목록과 함께 틀린 문제의 내 답, 정답, 해설이 따로 정리됩니다.
