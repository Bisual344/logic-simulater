NE555 타이머 · 핀과 연결

5단계의 TLC555는 CMOS형 555 타이머입니다. 기본 핀 구성과 RC 연결은 같지만 출력 전압 등 전기적 규격은 다르므로 실제 부품의 데이터시트를 확인하세요.

  1. 1번 GND, 8번 +5V, 4번 RESET은 +5V에 연결합니다.
  2. 2번 TRIG와 6번 THR를 서로 연결합니다.
  3. +5V → R₁ → 7번 DISCH → R₂ → 2·6번 순서로 연결합니다.
  4. 2·6번과 GND 사이에 C를 연결합니다. 전해 콘덴서의 +는 2·6번입니다.
  5. 5번 CTRL과 GND 사이에는 10nF, 8번과 1번 사이에는 100nF를 연결합니다.
  6. 3번 OUT → 1kΩ → LED 애노드(+), LED 캐소드(−) → GND로 연결합니다.

콘덴서가 충전·방전을 반복하면 3번에서 HIGH/LOW가 반복됩니다. TRIG가 전원의 1/3보다 낮아지면 출력을 HIGH로, THR가 2/3보다 높아지면 LOW로 바꿉니다. RESET=0은 출력을 LOW로 만듭니다.

NE555 출력의 HIGH 전압은 전원과 정확히 같지 않습니다. 74HC 입력과 직접 연결할 때는 실제 HIGH 규격을 확인하고 필요하면 버퍼 또는 CMOS 555를 사용하세요.

반가산기

쉽게 생각하면
1비트 덧셈은 작은 덧셈입니다. 0+0=0, 0+1=1, 1+0=1입니다. 그런데 1+1=2는 이진수로 10이라 출력 두 개가 필요합니다.

숫자로 확인하기
오른쪽 자리 Sum은 XOR로, 왼쪽 자리 Carry는 AND로 만듭니다. A=1, B=1을 넣으면 Sum=0, Carry=1 → 10₂가 됩니다.

Sum = A ⊕ B / Carry = A·B

A,B,Cin → XOR/AND/OR → Sum,Cout

전가산기

쉽게 생각하면
세 수를 더하는 덧셈 블록입니다. A와 B는 이번 자리의 숫자이고 Cin은 바로 아래 자리에서 올라온 1입니다.

숫자로 확인하기
먼저 A와 B를 더하고, 그 합에 Cin을 더합니다. A=1, B=0, Cin=1이면 총 2이므로 Sum=0, Cout=1입니다. 전가산기 4개를 연결하면 4비트 덧셈기가 됩니다.

Sum = A ⊕ B ⊕ Cin

2자리 디지털 스톱워치

00 → 99 · 1초씩 측정

가상 회로의 범위 · 이 실험은 지정한 디지털 연결을 검사하는 교육용 모형입니다. 전압·전류·아날로그 파형이나 임의 회로를 해석하는 SPICE 시뮬레이터가 아닙니다. 부품 이동은 배치 연습이며 단자 클릭으로 배선합니다. 화면의 디코더↔표시기 선에는 세그먼트별 1kΩ 저항이 내장된 것으로 모델링합니다. 실물에서는 반드시 별도 저항을 넣으세요. 기능 블록의 내부 배선과 고정 제어 핀은 아래 안내를 참고하세요.

준비물

  • TLC555 · 발진 회로 / 74HC08 · 시작/정지 게이트 / START/STOP 스위치 / 74HC192 · 일의 자리 / 74HC192 · 십의 자리 / CD4511 1 · BCD 디코더 / CC 7세그먼트 1 / CD4511 2 · BCD 디코더 / CC 7세그먼트 2
  • 브레드보드, 점퍼선, 안정화 5V 전원
  • 각 IC 전원에 100nF × IC 수, 스위치 풀업/풀다운 10kΩ, 버튼 디바운스 회로
  • 공통 캐소드 표시기 2개 및 세그먼트 1kΩ 저항 14개 · 555용 R₁·R₂·C 및 10nF

만들기 순서

  1. TLC555를 비안정 모드로 구성해 약 1Hz를 만듭니다. R₁=10kΩ, R₂=68kΩ, C=10µF이면 약 0.99Hz입니다. 정밀 시계용이 아니라 학습용 근사값입니다.
  2. 555 OUT(3) → 74HC08 입력 1, RUN 스위치 → 입력 2, 출력 3 → 일의 자리 74HC192 UP(5)을 연결합니다. RUN=1에서만 펄스가 통과합니다.
  3. 일의 자리 CARRY(12) → 십의 자리 UP(5)을 연결합니다. 두 카운터의 DOWN(4)은 HIGH로 고정합니다. 9 다음 0이 될 때 십의 자리가 증가합니다.
  4. 각 카운터 QA/QB/QC/QD를 각 CD4511 A/B/C/D에 연결하고, 디코더의 a~g는 저항을 거쳐 공통 캐소드 표시기로 보냅니다.
  5. MR(14)을 잠깐 HIGH로 만들면 00으로 초기화합니다. 시작·정지 후 재시작하면 이어서 셉니다. 99 다음 00으로 돌아갑니다.
실제 IC 핀 번호와 고정 제어 핀 · 반드시 펼쳐 읽기
핀 번호는 아래 명시한 DIP 제품 기준입니다. 실제 부품의 제조사·패키지 데이터시트를 먼저 확인하세요. 74xx 기능 번호가 같아도 HC/LS 혼용은 전압 호환성을 확인해야 합니다. 버튼 접점 튐은 RC+74HC14 등으로 제거하고, 실제 클록 게이팅은 클록 LOW 동안 RUN을 변경하도록 설계해야 가짜 펄스를 막을 수 있습니다.
IC연결 기준
TLC555 DIP-81=GND, 8=VCC, 4=RESET(HIGH), 2·6 연결, 7=방전, 5=10nF→GND, 3=OUT. 저항·콘덴서 연결은 2단계 NE555 안내와 같으며 로직 호환성을 위해 CMOS TLC555 권장. 보드의 555 블록은 RC 부품 포함.
74HC192 DIP-1616=VCC, 8=GND. QA/QB/QC/QD=3/2/6/7. UP=5, DOWN=4. CARRY=12, BORROW=13(LOW 활성). /PL=11은 평소 HIGH, MR=14는 평소 LOW·초기화 시 HIGH. 병렬 A/B/C/D=15/1/10/9. 병렬 입력은 기본 0에 고정. 업 카운트는 DOWN=1, 다운 카운트는 UP=1. 이 고정 제어 핀은 화면에서 생략.
CD4511 DIP-1616=VDD, 8=VSS(GND). BCD A/B/C/D=7/1/2/6. a/b/c/d/e/f/g=13/12/11/10/9/15/14. LE(5)=LOW, /BI(4)=HIGH, /LT(3)=HIGH. 공통 캐소드 표시기 사용. 각 출력→개별 저항→해당 a~g, COM→GND. 표시기의 다리 번호는 제품별 확인. 보드에서는 고정 제어 핀과 저항을 생략하여 표시.
74HC86 / 74HC0814=VCC, 7=GND. 게이트별 (입력,입력→출력)=(1,2→3), (4,5→6), (9,10→8), (12,13→11). 룰렛 HC08은 각 첫 입력=클록, 두 번째 입력=RUN, 출력=카운터.
74HC74 DIP-1414=VCC, 7=GND. 첫 FF: /CLR1, D2, CLK3, /PRE4, Q5, /Q6. 둘째 FF: /Q8, Q9, /PRE10, CLK11, D12, /CLR13. 비동기 /PRE와 /CLR는 LOW 활성, 평소 HIGH이며 둘 다 LOW로 만들지 않습니다. 반응게임·신호등 제어 블록의 핀 이름은 기능 단자이며 완성된 실물 핀 배선도를 뜻하지 않습니다.

실물 제작 범위: 스톱워치·룰렛은 위 핀 대응을 사용해 기본 기능을 구성합니다. 주차장의 경계 검출·입출차 중재·누적 집계, 반응게임의 자동 랜덤 대기/부정출발 판정과 신호등의 FSM·자동 로드 회로는 기능 수준 안내이며, 바로 제작 가능한 전체 핀 배선도는 아닙니다. 실제 실험은 교사 지도 아래 전원을 끈 상태에서 배선하고 단락을 확인한 뒤 켜세요.
